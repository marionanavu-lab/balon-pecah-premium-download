## Cara pasang di Android TV

1. Unduh APK lewat HP atau laptop.
2. Kirim ke TV dengan flashdisk atau aplikasi *Send Files to TV*.
3. Buka file APK dengan file manager di TV. Kalau diminta, izinkan "Instal aplikasi tidak dikenal".
4. Buka **Balon Pecah Premium**, tekan **Mulai**, lalu scan QR dengan HP supaya HP menjadi kamera.

Versi gratis "Balon Pecah" yang sudah terpasang tidak tertimpa, karena keduanya aplikasi terpisah.
